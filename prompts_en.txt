10 AI PROMPTS FOR YOUR DREAM JOB — vCode
Copy a prompt, replace every [paste ...] with your own text, and run it in ChatGPT, Claude or any AI chat.
Honesty rule: every prompt tells the AI to use only your real experience. Always read and check the output before you send anything.

==== PROMPT 1 — DECODE THE JD ====
You are an experienced technical recruiter. Read the job description below and break it down into one table with four columns: Must-have skills, Responsibilities, ATS keywords (exact phrases as written in the JD), and Standout traits the hiring manager will look for. After the table, list the 5 things my CV must prove for this role. Do not assume anything that is not in the JD.

==== PROMPT 2 — TAILOR THE CV ====
Rewrite my CV for the job below. Change only the summary, the experience bullets and the skills section, and use the JD's own keywords wherever they truthfully match my experience. Rules: use only facts from my CV; never invent jobs, skills, tools, degrees or numbers. If a JD skill is missing from my CV, do not add it — list it at the end under "Gaps".

CV: [paste CV]
JD: [paste JD]

==== PROMPT 3 — REWRITE THE BULLETS ====

JD: [paste JD]

==== PROMPT 4 — WRITE THE COVER LETTER ====

==== PROMPT 5 — BUILD A ROLE-FIT MATRIX ====

Add a keyword to the summary only if my CV supports it.

JD: [paste JD]

Keep each answer under 150 words. Where a result has no number, write [ADD METRIC]. If my background has no real story for a theme, say so instead of making one up.
